# 跳一跳

经典跳一跳：等距视角的方块地板，小人站在一块上，**按住蓄力，松开起跳**，跳多远取决于按了多久，落到下一块方块上得分，落空就掉下去。

## 玩法

1. 启动器里选“跳一跳”，按住 500ms 进入；标题页显示最高分，**短按开始**。
2. 画面里下一块方块在小人的左上或右上（沿两条对角线交替，路径是之字形）。小人的方向总是瞄准下一块的中心，**只有距离要自己掌握**：按得越久跳得越远（每秒 28 个单位，最短点一下也会跳三个单位，按满 1.4 秒会自己起跳）。
3. 结果：
   - **落在方块中心附近（1.5 个单位内）= 完美**：得 2×连击分，连击每次完美加一，最多 6；
   - **落在方块上 = 好**：得 1 分，连击清零；
   - **原地没跳出去（还站在原来的方块上）**：不得分，连击清零，再来一次；
   - **落空**：小人摔下去，本局结束，显示分数和最高分，短按再来。
4. 随着分数增加，方块会变小（半宽从 11 缩到 7）、间距会变大；每次落点还有“完美+N”“+N”飘字，连击显示在状态栏。

## 退出

跳一跳靠的是计时按住，而不是连按，所以**保留全局三击回菜单**，没有按住退出（蓄力要按住很久，不能把长按当成退出）。

## 实现

- `apps/jump/firmware/jump_core.{h,c}`：纯 C，位置用地板单位的 1/16，跳跃方向用 1/256 的单位向量，每次都从落点瞄准下一块的中心；一次跳跃是 `jp_press()`（蓄力）→ `jp_release()`（起跳，算出落点和结果）→ 飞行 → 落地/摔落。主机测试用 `jp_charge_for()` 算出“正好”的蓄力时长，验证每一跳都能完美，也验证偏差多大会变成“好”“原地”“落空”。
- `apps/jump/firmware/app.c`：共享画布画等距地板、方块的侧面和顶面、阴影、压扁拉伸的小人和跳起弧线；LVGL 放分数、最高分、连击和飘字。不用雷达和舵机。

## USB 调试命令

```text
robot jump status
```

返回 `active`、`phase`（0 标题 1 就绪 2 蓄力 3 飞行 4 落地 5 摔落 6 结束）、`cur`（当前方块序号）、`combo`、`score`、`best`、`jumps`、`perfects` 和 `frames`。
