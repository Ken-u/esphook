# GPIO6 投篮游戏

## 接线

新增一个常开按键：一端接 **GPIO6**，另一端接 **GND**。固件启用内部上拉，按下为低电平，无需额外上拉。GPIO6 专供该按键，不能再用于雷达或舵机；GPIO10 仍为舵机 PWM，GPIO20/21 仍为雷达串口。原 K2/K3 不接入机器人模式。

按键每 5ms 采样，电平稳定 25ms 后产生一个按下事件；长按不连发。上电时若按键已按住，必须先松开再按，避免启动误触。

## 玩法

1. 在表情、文字或雷达页，**800ms 内快速按三次**进入游戏。三击只用于入场，不计出手。
2. 倒计时从 **02:00** 开始。篮筐从左到右移动，走到右侧后回到左侧继续。
3. 球从屏幕中央出手。篮筐中心进入屏幕中心 **±10 像素**范围时按下即命中；中央绿色区域表示判定窗口，篮圈在窗口内也会变绿。
4. 每次按下投一球，显示约 **650ms** 飞行/落球动画，期间篮筐冻结，额外按下忽略。命中显示绿色反馈，未进显示红色反馈。
5. 每次出手后，无论进没进，下一轮都从左侧开始，并随机选一个与上一轮不同的 **36–100 像素/秒**速度。
6. 每投中一次得 **2 分**。时间到立即停止接收投篮，结算显示投中次数、得分、总出手数和整数命中率。

判定采用消抖后按下事件的时间戳和当时的篮筐位置，独立于屏幕刷新次数。650ms 动画也计入两分钟总时长；截止前已接收的投篮计入结果，截止时及之后的投篮不计分。

游戏约 30 帧/秒刷新；按键事件和计时器仍由单独输入采样及显示任务处理，雷达接收任务照常运行。

## 结束与退出

结束后保留成绩页。为避免最后一刻的连按立刻跳过结果，成绩页至少显示 750ms；之后**单击返回原来的显示页，快速三击可再玩一局**。再次入场会清零当局数据，每局重新随机初始化速度。

游戏是临时覆盖层，不修改原表情/文字/雷达配置；退出后显示当前底层配置，其原有 TTL 仍按真实时间流逝。游戏期间通过显示协议更新的内容会在退出游戏后显示。

游戏不改变舵机的 arm/follow/校准状态，也不使用摄像头、麦克风或联网功能；只想安静玩屏幕游戏时，可先用现有 `robot disarm` 关闭 PWM。成绩保存在 RAM，不记录跨重启最高分。

## USB 调试命令

```text
robot game start
robot game status
robot game stop
```

- `start`：直接开始或重新开始一局，方便尚未接按键时调试。
- `status`：返回阶段 `off/playing/result`、剩余秒数、出手数、命中数、得分和下一轮速度。
- `stop`：退出游戏并恢复底层显示，不影响舵机。

命令和物理按键事件排入同一游戏队列，游戏状态与所有 LVGL 控件只由显示任务修改。
