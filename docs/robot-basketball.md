# GPIO6 投篮游戏

## 接线

新增一个常开按键：一端接 **GPIO6**，另一端接 **GND**。固件启用内部上拉，按下为低电平，无需额外上拉。GPIO6 专供该按键，不能再用于雷达或舵机；GPIO10 仍为舵机 PWM，GPIO20/21 仍为雷达串口。原 K2/K3 不接入机器人模式。

按键使用 GPIO 双边沿中断。ISR 只通知输入任务；任务在最后一次边沿通知后等待电平稳定 25ms，再产生按下/松手事件。空闲与长按期间任务阻塞，不做周期轮询；长按不连发。上电时若按键已按住，必须先松开再按，避免启动误触。

## 玩法

1. 待机短按打开启动器，选择“投篮”，按住 **500ms** 画满确认圆进入。任何页面三击都回菜单；旧三击进投篮取消。进入时的松手不计出手。
2. 倒计时从 **02:00** 开始。篮筐从左到右移动，走到右侧后回到左侧继续。
3. 球从屏幕中央出手。篮筐中心进入屏幕中心 **±10 像素**范围时短按松手即命中；中央绿色区域表示判定窗口，篮圈在窗口内也会变绿。
4. 每次短按松手投一球，显示约 **650ms** 飞行/落球动画，期间篮筐冻结，额外短按忽略。命中显示绿色反馈，未进显示红色反馈。
5. 每次出手后，无论进没进，下一轮都从左侧开始，并随机选一个与上一轮不同的 **36–100 像素/秒**速度。
6. 每投中一次得 **2 分**。时间到立即停止接收投篮，结算显示投中次数、得分、总出手数和整数命中率。

判定采用消抖后短按松手事件的时间戳和当时的篮筐位置，独立于屏幕刷新次数。650ms 动画也计入两分钟总时长；截止前已接收的投篮计入结果，截止时及之后的投篮不计分。

游戏约 30 帧/秒刷新；按键事件和计时器仍由中断唤醒的输入任务及显示任务处理，雷达接收任务照常运行。

## 结束与退出

结束后保留成绩页，短按返回菜单。任何时候 800ms 内三次有效按下回菜单，第三次松手被消费；前两次短按仍可能出手，以保留即时响应。重新从菜单确认进入即开始新局，清零数据并重新随机初始化速度。

游戏是临时覆盖层，不修改原表情/文字/雷达配置；回菜单后无操作 10s 恢复自动表情，其原有 TTL 仍按真实时间流逝。游戏期间通过显示协议仍可更新后台配置。详见 [全局启动器](robot-launcher.md)。

游戏不改变舵机的 arm/follow/校准状态，也不使用摄像头、麦克风或联网功能；只想安静玩屏幕游戏时，可先用现有 `robot disarm` 关闭 PWM。成绩保存在 RAM，不记录跨重启最高分。

## USB 调试命令

```text
robot game start
robot game status
robot game stop
```

- `start`：直接开始或重新开始一局，方便尚未接按键时调试。
- `status`：返回当前应用编号、菜单选择、剩余秒数、出手数、命中数和得分。
- `stop`：退出游戏并恢复自动表情，不影响舵机。`robot menu` 可直接开启动器。

命令和物理按键事件排入同一游戏队列，游戏状态与所有 LVGL 控件只由显示任务修改。

./scripts/test-basketball.sh
