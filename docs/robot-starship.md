# 星际战机

第一人称驾驶战机穿过小行星带，迎战敌方巡逻舰。**雷达控制左右，按键开炮，被击中舵机轻摇一下并掉一滴血，一共 3 滴。**

## 玩法

1. 待机短按打开启动器，选择“星际战机”，按住 **500ms**（高亮条填满）进入，标题画面显示“星际战机”和最高分。最高分保存在设备上（`app_best`）：退出游戏、重启后仍在；只在一局结束时、且破纪录才写一次 flash。
2. 在标题或“战机损毁”画面**短按一下开局**（这一按之前开始于游戏中的按键不算开局，所以打到最后一下不会立刻重开）。
3. 转向：
   - **雷达**：站在雷达前，开局时离雷达最近的人被当作飞行员，他当时所站的位置是正中；向左或向右**侧身/移动约 35cm** 就是满舵，25mm 以内死区。目标丢失后保持最后的转向 1.2 秒再缓缓回中；另一个人走过（位置突然跳变超过 50cm）不会抢走控制权。
   - **按键**：K2 向左、K3 向右（USB 虚拟按键也一样），约 0.3 秒推到满舵，松开 0.18 秒回中；有按键操作时按键优先于雷达。
4. **按住主按键（K1）持续开炮**，每 0.18 秒一发，左右两门炮交替。炮弹打向正前方，命中远处的目标。
5. 目标：
   - **小行星**：小块一发打碎得 10 分，大块要三发、得 30 分，碎裂时迸成火花；
   - **敌舰**：从远处飞入，悬停并向你发射光弹，**两发**击落得 100 分；约 9 秒还没打掉它就会俯冲撞来。
6. 掉血：被光弹击中或与目标相撞，**扣一滴血**（共 3 滴，座舱仪表盘左侧三颗红心），船体抖动、屏幕泛红，之后有 1.2 秒无敌；扣完最后一滴，战机爆炸，约 1.2 秒后出现“战机损毁”画面，显示“击落 N 最高 M”。
7. 难度随时间上升，约 150 秒达到最高：小行星更密，敌舰出现得更频繁。

**连点开炮不会再退出**：这个游戏屏蔽了全局三击。回菜单的办法是在标题或“战机损毁”画面**按住按键 2 秒**（底部提示和“按住2秒退出”交替出现，按住时有金色→红色的进度线，金色段仍是 500ms 启用舵机）；游戏中不能退出，打完这一局（被击毁）再退。游戏中一直按着开炮、直到被击毁，那次按住也不会在结束画面退出。

## 舵机

- 保存过舵机校准的机器人进入游戏时自动启用受击反馈，右上角出现“舵机”标签。标题或“战机损毁”画面的 500ms 长按也可手动启用。
- 飞行时舵机随战机向左右移动，最大约 4°。
- 启用后每掉一滴血摇一下，摇的幅度和时长按剩余血量调整：前两滴轻摇（约 4°，0.5 秒），最后一滴摇得更狠更久（约 7°，0.9 秒）。摇晃通过 `app_haptic.h` 按舵机服务的限位和限速换算，不绕过校准/限位/限速。
- 没有舵机、未启用或故障时，游戏照常，只是不摇。退出应用由框架强制 disarm。

## 实现

- `apps/starship/firmware/starship_core.{h,c}`：纯 C 核心，无 ESP/LVGL 依赖，固定 20ms 步进（一次最多处理 200ms，更长间隔视为暂停），所以结果与 tick 频率无关。世界用定点整数：x 是左右、z 是前方距离，物体到 z=100 时撞船；炮弹按扫掠判定，不会穿过高速目标。`ss_take_hit()` 对每个丢掉的血量返回一次，由应用在 tick 里用来驱动舵机。
- `apps/starship/firmware/app.c`：共享画布做第一人称透视：星空、行星、星云、小行星（三款体素模型，按种子选形状和色调，翻滚，矿脉发光）、敌舰（体素模型，机翼、机身、翼尖炮、眼睛，带倾侧和摇摆）、你机翼上的两门炮（体素模型）、炮弹/光弹/爆炸（仍是平面），座舱框、仪表盘上的三颗红心、小雷达（左右偏差和远近）、雷达/按键/舵机三盏状态灯、瞄准准星（对准目标时变红闪烁）、光弹将至时顶部的闪烁箭头；LVGL 只用于分数、血量、底部提示和卡片文字。体素模型是**切片堆叠**（`starship_models.c`，`esphook/app_stack.h`，见 [stack-render.md](stack-render.md)），半宽不到 5 像素的远处目标仍是平面精灵；`robot starship status` 的 `vox=` 是这一帧画了多少体素。转向来自 `app_steer.h`（雷达/按键；雷达按站在机器前面的人的视角，向你的右边侧身就是向右转），舵机来自 `app_haptic.h`，都不直接接触硬件。事件 `DOWN/UP` 开炮，`SHORT` 开局，`CONFIRM` 启用舵机，`CANCEL`（USB 租约丢失）停火。会话状态小于 2048 字节，核心是状态的第一个成员，编译期有 `_Static_assert`。

## USB 调试命令

```text
robot starship status
```

返回 `active`、`phase`（0 标题 1 飞行 2 爆炸中 3 结束）、`hp`、`score`、`best`、`kills`、`shots`、`steer`（-256..256）、`cam`（船的位置）、`objs`、`foes`、`src`（转向来源 0 无 1 雷达 2 按键）、`servo`（0 无 1 未启用 2 已启用 3 故障）和 `frames`。

## 验证

```bash
./scripts/test-stack.sh          # 切片堆叠和小行星、敌机、机翼炮体素模型：格式、尺寸（石头 9 体素宽、敌机 15）、字母与调色板、越界与包围盒
./scripts/test-starship.sh       # 核心：转向与限速、开炮节奏、命中与击落、三滴血与无敌、爆炸后结束、自动驾驶 vs 原地不动的平衡、随机压力
./scripts/test-haptic-steer.sh   # 舵机摇晃/限位限速，雷达与按键转向
./scripts/test-app-ui.sh         # 真实 LVGL 渲染：标题、飞行、开炮、命中、爆炸、结束卡（近景、特写里的体素数在预算内），雷达桩转向、舵机桩只在确认后启用并在掉血时摇晃
```

未接雷达/舵机时，只能验证屏幕和 K2/K3 转向；雷达和舵机路径靠核心测试与无屏渲染中的雷达/舵机桩覆盖，**没有在真实雷达、舵机上验证**。
