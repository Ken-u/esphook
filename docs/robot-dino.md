# 小恐龙（离线跳跃）

灵感来自 Chrome 断网页面的恐龙跑酷。单键游戏：恐龙固定在左侧自动奔跑，障碍物从右侧迎面而来，用同一个按键起跳。

## 玩法

1. 待机短按打开启动器，选择“小恐龙”，按住 **500ms** 画满确认圆进入。进入时的松手不计输入。
2. 标题画面按一下键：开始奔跑并起跳。
3. **按下立即起跳**（不等松手）。**按住跳得更高，松手提前收跳**：
   - 一直按住：约 **24 像素**高、空中约 **0.58 秒**，能越过大仙人掌、双仙人掌和低飞翼龙；
   - 轻点：只起跳约 **13 像素**、空中约 0.40 秒，只够越过小仙人掌；
   - 空中再按无效，没有二段跳。
4. 障碍：小仙人掌、大仙人掌、双仙人掌；约 **150 分**后出现翼龙。**低飞翼龙要跳过去，高飞翼龙（悬在半空）不要跳**——站着从下面走过，起跳反而会撞上。
5. 速度从 **90 像素/秒**起每秒增加 1.2，到 **190 像素/秒**封顶（约 83 秒）。得分 = 跑过距离 / 10，屏幕显示五位，左上是本次开机内的最高分。
6. 撞上障碍后恐龙变红，显示“游戏结束”，**500ms 内按键无效**（避免连点直接跳过结果），之后按键重新开始。超过先前最高分会显示“新纪录!”；首局不显示。

任何页面 800ms 内快速三击回菜单；这是全局手势，所以**空中别连点三下**——空中的按键本来就无效，连点只会触发回菜单。

## 障碍保证可通过

障碍间隔按**时间**生成：相邻两个障碍到达恐龙的时间差随机落在 **0.9–2.0 秒**，按当前速度折算成距离，所以速度再快也留得出一次完整跳跃（0.58 秒）加落地余量。前 120 像素没有障碍；翼龙出现前不会遇到。

## 实现

- `apps/dino/firmware/dino_game.{h,c}`：纯 C 规则，无 ESP/LVGL 依赖。**固定 1ms 步长**推进，结果只由随机种子和带时间戳的按键事件决定，与 tick/刷新频率无关；停顿超过 2 秒视为暂停而不是补算。
- `apps/dino/firmware/dino_sprites.h`：恐龙（两帧奔跑）、两种仙人掌、翼龙（两帧）的点阵。
- `apps/dino/firmware/app.c`：用框架共享的 160×48 画布 `app_ui_pixels()` 逐像素绘制（云、地面、障碍、恐龙），上方是分数行，下方是提示行，退出时释放共享画布。游戏核心 120 字节，应用会话状态远小于 2048 字节会话区（编译期 `_Static_assert` 保证）。

按键事件用 `DOWN` / `UP` / `CANCEL`：`DOWN` 起跳，`UP` 与 `CANCEL`（USB 按住租约失效）收跳。`SHORT` / `CONFIRM` 忽略，不再重复触发。

## USB 调试命令

```text
robot dino start
robot dino status
robot dino stop
```

- `start`：排队打开小恐龙；`stop`：回菜单；
- `status`：`phase`（0 待开始 / 1 奔跑 / 2 结束）、`score`、`best`、`speed`、当前屏幕障碍数。

## 验证

```bash
./scripts/test-dino.sh
```

纯 C 测试启用 AddressSanitizer/UBSan，覆盖：点阵每行等宽、尺寸与物理一致；满按/点按/中途松手/越过顶点后松手的跳跃高度和滞空时间；无二段跳；五种障碍的碰撞盒上下左右边界（刚好越过 / 刚好撞上）；不同 tick 节奏（5ms / 33ms / 一次性）逐字节相同的结果；十分钟级停顿；撞上后世界冻结、500ms 内不能重开、重开后最高分保留、新纪录判定；以及机器人模拟：

- 满按、把最高点对准障碍中心的“完美”玩家，20 个种子各跑 **200 秒**全部不死，得分 > 2400，速度达到 190 封顶，障碍间隔 0.90–2.00 秒，五种障碍都出现，150 分前没有翼龙；
- 把按键时机统一提前或推迟 **±80ms** 仍然 20/20 全部撑过 60 秒；**±120ms** 就全部失败（容错窗口约 ±100ms）；
- 对一切障碍都跳（包括高飞翼龙）：20/20 死于高飞翼龙；一直轻点：20/20 死于高障碍。

真 LVGL 无屏渲染（`./scripts/test-app-ui.sh`）会开始游戏、起跳、撞上并重新开始，并断言屏幕上的每个汉字都在固件字库里。

**尚未实机验证**：按键手感、30 帧/秒的实际流畅度（无屏测试不能证明 FPS）和肉眼难度需要刷机确认。可调参数在 `dino_game.h`：`DINO_JUMP_V` / `DINO_GRAVITY`（跳跃高度与滞空）、`DINO_SPEED_*`（速度曲线）、`DINO_GAP_MIN_S` / `DINO_GAP_MAX_S`（障碍间隔）。
