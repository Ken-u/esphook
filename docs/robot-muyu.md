# 电子木鱼

敲一下，**功德 +1**。

## 玩法

1. 待机短按打开启动器，选择“电子木鱼”，按住 **500ms** 画满确认圆进入。进入时的松手不计敲击。
2. **按下的瞬间就敲**（不等松手）：木槌落下，木鱼被敲扁再弹回，一圈圈金色涟漪扩散，木鱼上方飘起金色的 **“功德+1”** 并渐隐；左上角计数同步增加。
3. **长按（500ms）开关自动敲**：自动模式每秒一下，右上角亮“自动”标签；再长按关闭。长按过程中底部有一条进度线。自动期间手动也能敲，不改变自动的节拍。
4. 每敲满 **108** 下（一串念珠）飘出 **“功德圆满”**。计数上限 99,999,999。
5. 画面：夜色里的金色光晕（每敲一下亮一下）、飘升的光点、香炉和袅袅青烟、红色蒲团上的木鱼和木槌。

**注意**：任何页面 800ms 内快速三次按下都会回菜单（全局手势，框架统一处理），所以快速连敲三下会退出。木鱼的节奏本来就慢，平均间隔大于 0.4 秒就不会触发；想不停地敲请用自动模式。功德只保存在本次进入期间，退出后清零。

## 实现

- `apps/muyu/firmware/muyu_core.{h,c}`：纯 C 规则，无 ESP/LVGL 依赖。只用传入的时间戳记时，所以自动节拍与 tick 频率无关；停顿超过 3 秒视为暂停，不补算敲击；计数、108 圈标记和最近两次敲击的年龄（浮字用两个槽位交替，允许叠放）都由它给出。
- `apps/muyu/firmware/app.c`：共享画布画木鱼/木槌/涟漪/火花/光晕/香炉，LVGL 只用于左上计数、右上“自动”标签、两个浮字标签和底部提示，绘图函数来自 `app_gfx.h`（渐变、椭圆光晕、圆环、`gfx_isqrt` 整数开方）。事件用 `DOWN` 敲击、`CONFIRM` 开关自动。会话状态远小于 2048 字节区，编译期有 `_Static_assert`。

## USB 调试命令

```text
robot muyu status
```

返回 `active`、`count`、`auto`、`rounds`（满 108 的圈数）、`frames`（已渲染帧数）。
