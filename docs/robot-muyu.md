# 电子木鱼

敲一下，**功德 +1**。

## 玩法

1. 待机短按打开启动器，选择“电子木鱼”，按住 **500ms**（高亮条填满）进入。进入时的松手不计敲击。
2. **按下的瞬间就敲**（不等松手），计数立刻加一，木槌从右上角挥下来：
   - 约 **0.1 秒**加速下落（带几帧残影），**敲在木鱼顶上**——木槌头压住木鱼，木鱼被压扁、变宽，闪出一圈星芒和火花；
   - 敲中的瞬间才飘起金色的 **“功德+1”**（右侧上升并渐隐），金色涟漪一圈圈扩散，光晕亮一下；
   - 压住约 0.07 秒后被木鱼弹回，轻微过冲后在上方待命；整个动作 0.36 秒。连敲时下一次从木槌当前的位置接着挥，不会瞬移；新一次敲中时上一个“功德+1”快速让位。
3. **长按（500ms）开关自动敲**：自动模式每秒一下，右下角亮“自动”标签；再长按关闭。长按过程中底部有一条进度线。自动期间手动也能敲，不改变自动的节拍。
4. 每敲满 **108** 下（一串念珠）飘出 **“功德圆满”**。计数上限 99,999,999。
5. 画面：夜色里的金色光晕（每敲一下亮一下）、飘升的光点、香炉和袅袅青烟、红色蒲团上的木鱼和木槌。

**退出**：木鱼屏蔽了全局三击，快速连敲不会退出；**按住按键 2 秒**回菜单（500ms 时先切换自动模式，进度线先金色后红色，底部提示“按住2秒退出”）。功德只保存在本次进入期间，退出后清零。

## 实现

- `apps/muyu/firmware/muyu_core.{h,c}`：纯 C 规则，无 ESP/LVGL 依赖。只用传入的时间戳记时，所以自动节拍与 tick 频率无关；停顿超过 3 秒视为暂停，不补算敲击；计数、108 圈标记、最近两次敲击的年龄（两个槽位交替）、距离上次“敲中”的时间和木槌挥动的起点都由它给出。`muyu_lift()` 是木槌高度的时间函数（下落—压住—弹回），主机测试覆盖其连续性、单调性和中断后的衔接。
- `apps/muyu/firmware/app.c`：共享画布画木鱼/木槌/涟漪/火花/光晕/香炉，LVGL 只用于左上计数、右下“自动”标签、两个浮字标签和底部提示，绘图函数来自 `app_gfx.h`（渐变、椭圆光晕、圆环、`gfx_isqrt` 整数开方）。木槌是以“手”为支点的一根带红色握把的木棍加球形槌头，槌头始终贴着木鱼上沿（`fish_top()`），所以会被压扁的木鱼顶起。事件用 `DOWN` 敲击、`CONFIRM` 开关自动。会话状态远小于 2048 字节区，编译期有 `_Static_assert`。

## USB 调试命令

```text
robot muyu status
```

返回 `active`、`count`、`auto`、`rounds`（满 108 的圈数）、`frames`（已渲染帧数）。
