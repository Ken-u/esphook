# 极速赛车

第一人称公路赛，和星际战机同一套操作：**按键加速，雷达或 K2/K3 控制左右，撞车时舵机短摇，氮气定时充满。** 连点油门不会退出：游戏屏蔽了全局三击，回菜单是在标题或“时间到”画面**按住按键 2 秒**（提示和“按住2秒退出”交替出现，有进度线）。比赛中不能退出。

## 玩法

1. 待机短按打开启动器，选择“极速赛车”，按住 **500ms**（高亮条填满）进入，标题画面显示最高分。最高分保存在设备上（`app_best`）：退出游戏、重启后仍在；只在一局结束时、且破纪录才写一次 flash。
2. 在标题或“时间到”画面**短按一下出发**，倒数 3、2、1 后开跑（约 2.8 秒）。
3. **按住键加速**，松开滑行减速。最高 200 km/h，约 7.5 秒加到 190 km/h 左右。起步时间 **45 秒**。
4. 转向：
   - **雷达**：开局时离雷达最近的人是飞行员，当时的位置是正中；向左或向右**侧身约 35cm** 是满舵（25mm 以内死区），目标丢失后保持 1.2 秒再回中；
   - **按键**：K2 向左、K3 向右，约 0.3 秒推到满舵，松开 0.18 秒回中；有按键操作时按键优先。
5. 路是弯的：**速度越快，弯道把车往外推得越厉害**，要提前往弯里打方向。弯道在屏幕上画得比真实的弯更急（`BEND_VIEW` = 6 倍，不然 7 米宽的路在 160 像素里几乎是直的），远处的天际线和太阳随弯道平移，**弯道外侧立着黄底黑箭头的指示牌**（弯越急、牌越多）指出弯的方向；推力是实际弯度的 1.5 倍，不打方向就会往外滑。路面宽度之外是路肩，冲出路面会被拖慢到约 45 km/h；继续偏出撞上护栏会被弹回路面并损失大半速度。
6. 路上有同向行驶的车：从后面追上并超过它得 25 分（还按里程计分，每米 1 分）；撞上（追尾或侧撞）会损失速度（只保留约比对方慢 15 km/h 的速度，不低于 30）、0.6 秒内转向变迟钝、掉一半氮气。
7. **检查点**：每 1.4 公里一道龙门架，通过加 **24 秒**，路也会越来越难（约 8 公里达到最高难度：弯更急、车更多）。
8. **氮气**：油箱 10 秒从空充到满（右下角的条），满了底部提示“氮气就绪 双击按键”。**松开油门再在 0.28 秒内按回去（也就是点两下）**就点燃氮气：约 3 秒的最高 290 km/h，出现速度线和蓝色尾焰，用完后重新计时充能。撞车会掉一半氮气。
9. 时间到，车滑行停下（1.8 秒），出现“时间到”卡片：“里程 N 米 最高 M”。

任何页面 800ms 内快速三次按下会回菜单（全局手势）。点两下氮气是两次按下，**不要连点三下**。

## 舵机

- 保存过舵机校准的机器人进入游戏时自动启用碰撞反馈，右上角出现“舵机”标签。标题或“时间到”画面的 500ms 长按也可手动启用。
- 舵机随方向盘转动。撞车和启动氮气时额外短摇，动作通过 `app_haptic.h` 遵守校准限位和限速。
- 没有舵机、未启用或故障时，游戏照常，只是不转。退出应用由框架强制 disarm。

## 实现

- `apps/racing/firmware/racing_core.{h,c}`：纯 C 核心，无 ESP/LVGL 依赖，固定 20ms 步进（一次最多处理 200ms），位置用毫米、速度用 1/16 km/h、横向用千分比的整数定点。弯道曲率是沿路程的确定性函数（`rc_curve_at()`），由赛道种子生成，主机测试验证连续性和斜率上限（它是推车的“真”弯度，画面上由 `app.c` 乘 `BEND_VIEW` 放大）；弯道离心力、路肩阻力、护栏、交通车、检查点和氮气都在这里。
- 雷达转向按站在机器前面的人的视角：向你的右边侧身就是向右转。
- `apps/racing/firmware/app.c`：共享画布做伪 3D 公路：逐行用整数计算路中心和宽度（`build_rows`，唯一用到 64 位整数的地方），天空日落、远山、树和路灯、红白路缘、路面标线、龙门架、前方的交通车（只见车尾灯，越近越大；近处的车、树、路灯和龙门架是体素模型，见下）、速度线、撞车时的红闪和火花；座舱里有方向盘（随转向转动）、速度表、氮气条、倒计时。LVGL 只用于分数、提示和卡片。近处的交通车（三款）、80 米内的树和路灯、检查点龙门架是**切片堆叠的 3D 体素模型**（`racing_models.c`，`esphook/app_stack.h`，见 [stack-render.md](stack-render.md)），带阴影、远景雾、尾灯和刹车灯，随路的方向和你的位置转到合适的角度；更远的东西仍是平面精灵；`robot racing status` 的 `vox=` 是这一帧画了多少体素。事件 `DOWN/UP` 是油门，松开后 0.28 秒内再按下是氮气，`SHORT` 开局，`CONFIRM` 启用舵机，`CANCEL`（USB 租约丢失）松开油门。会话状态小于 2048 字节，核心是状态的第一个成员，编译期有 `_Static_assert`。

## USB 调试命令

```text
robot racing status
```

返回 `active`、`phase`（0 标题 1 倒数 2 比赛 3 滑行 4 结束）、`speed`、`px`（横向位置）、`dist`（米）、`time`（剩余秒）、`nitro`（0..1000）、`score`、`best`、`cps`（检查点数）、`crashes`、`steer`、`src`（转向来源 0 无 1 雷达 2 按键）、`servo`（0 无 1 未启用 2 已启用 3 故障）和 `frames`。

## 验证

```bash
./scripts/test-stack.sh          # 切片堆叠和车、树、路灯、龙门架体素模型：格式、尺寸（车宽 3.1 米）、字母与调色板、越界与包围盒
./scripts/test-racing.sh         # 核心：加速曲线、弯道连续性/斜率、离心力、路肩/护栏、交通车与超车、检查点加时、氮气充能/点燃/撞车损失、认真驾驶 vs 撒手不管的平衡、随机压力
./scripts/test-haptic-steer.sh   # 舵机摇晃/限位限速，雷达与按键转向
./scripts/test-app-ui.sh         # 真实 LVGL 渲染：标题、倒数、加速、转向、撞车、检查点、氮气、结束（弯道、撞车里的体素数在预算内），雷达桩转向、舵机桩确认后才启用
```

未接雷达/舵机时，只能验证屏幕和 K2/K3 转向；雷达和舵机路径靠核心测试与无屏渲染中的雷达/舵机桩覆盖，**没有在真实雷达、舵机上验证**。
