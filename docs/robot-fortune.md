# 今日幸运签

红漆签筒里一把竹签：**按住按键筒就摇起来，松手一支签跳出来，签文展开**。每一签都是吉签，只是从事业、人际、家庭、学业、爱情里随机抽一个方面，再随机定级：**大吉 25%、中吉 40%、小吉 35%**。签文里有一句对应这个方面和等级的祝福，下面一条是幸运数和幸运色。

## 玩法

1. 启动器里选“幸运签”，按住 500ms 进入；标题页的提示“按键摇签 按住摇得更久”，在设备已校时的情况下与当天日期交替显示。
2. **按住**按键：签筒摇晃，至少摇 1.2 秒，一直按住最多摇 4 秒；**松手**，一支签跳出（0.8 秒），签文展开。
3. 签面是金色印章的等级（大吉/中吉/小吉）、方面（“事业运”等）、祝福语；幸运数和幸运色与提示交替出现在底部条里。
4. 再按一下再抽一签；三击回菜单（框架手势）。每次进入都用新的随机种子，不保存历史。

松手太早也要摇满 1.2 秒；USB 租约丢失（CANCEL）当作松手。

## 实现

- `apps/fortune/firmware/fortune_core.{h,c}`：纯 C，只依赖时间戳；`ft_pick()` 用线性同余发生器按 25/40/35 抽等级、均匀抽方面，每个（方面，等级）有 3 条祝福；`ft_press/ft_release/ft_advance` 驱动摇签 → 跳签 → 展开 → 签面的状态机。
- `apps/fortune/firmware/app.c` 使用共享画布绘制签筒和签面。保存过校准的机器人随签筒左右摇动，出签时回中。

## USB 调试命令

```text
robot fortune status
```

返回 `active`、`phase`（0 待机 1 摇签 2 跳签 3 展开 4 签面）、`draws`、`category`（0 事业 1 人际 2 家庭 3 学业 4 爱情）、`level`（0 大吉 1 中吉 2 小吉）、`text`、`number`、`colour` 和 `frames`。
