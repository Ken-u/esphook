# 水族箱

一个会呼吸的海水缸：**按一下，扔一撮鱼食**，鱼群游过来抢着吃。

## 玩法

1. 待机短按打开启动器，选择“水族箱”，按住 **500ms**（高亮条填满）进入。进入时的松手不算投喂。
2. 水面上方有一只手来回移动（约 7 秒一个来回）。**按下的瞬间**手松开指尖，4 粒鱼食落在它当时所在的位置，水面溅起一圈涟漪。投喂有 160ms 冷却，水里同时最多 20 粒。
3. 鱼食边下沉边左右摇晃，附近的鱼会转头游过去吃：小丑鱼、蓝吊、天使鱼、一群四线脂鲤、水母，沙地上的螃蟹会横着爬去捡落到底的食物。吃到的瞬间鱼嘴边冒出一颗小气泡，同时累计“进食”次数。
4. 一条鱼吃饱（连吃几粒）后 6 秒内不再理会食物；没吃掉的鱼食落到沙上 8 秒后溶解。
5. 画面：从水面透下的光柱、水草摇摆、珊瑚、小丑鱼的海葵家、宝箱冒泡、沙地纹理。左上显示“投食 N”和“进食 N”，底部提示“按键投食”。
6. 没有胜负，也没有结束；连点投喂不会退出：水族箱屏蔽了全局三击，**按住按键 2 秒**回菜单（底部有提示，按住时有进度线）。

## 实现

- `apps/aquarium/firmware/aquarium_core.{h,c}`：纯 C 模拟核心，无 ESP/LVGL 依赖。固定 10ms 步进，`aq_advance()` 一次最多处理 250ms（更长的间隔视为暂停，不补算），所以结果与 tick 频率无关。鱼各自有游动目标、尾巴相位和“吃饱”计时；鱼食是下沉加摆动的粒子；气泡池固定大小。位置用 1/256 像素的定点数，没有浮点。
- `apps/aquarium/firmware/app.c`：共享画布画整个缸（渐变水色、光柱、水草、珊瑚、鱼的身体用 `app_fish.h` 里的共用鱼形），LVGL 只用于计数和提示。事件只用 `DOWN`（投喂）。会话状态远小于 2048 字节区，编译期有 `_Static_assert`。
- 不使用雷达和舵机。

## USB 调试命令

```text
robot aquarium status
```

返回 `active`、`thrown`（投喂次数）、`eaten`（吃掉的鱼食数）、`food`（水里的鱼食数）、`frames`（已渲染帧数）。

## 验证

```bash
./scripts/test-aquarium.sh   # 核心：投喂/冷却/上限、鱼食下沉与溶解、鱼追食并吃饱、螃蟹、气泡、长时间随机压力、tick 频率无关
./scripts/test-app-ui.sh     # 真实 LVGL 渲染：投喂前后帧图、计数、气泡与鱼食出现、进出应用
```
