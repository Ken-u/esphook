# 滑雪冒险

致敬 SkiFree 的单键下滑游戏：滑雪者沿雪坡向下滑，树木和石头从下方卷上来，躲开它们，别被雪怪追上。

## 玩法

1. 待机短按打开启动器，选择“滑雪冒险”，按住 **500ms** 画满确认圆进入。
2. 标题画面按一下键开始，滑雪者出发时向**右下**滑。
3. **每按一下键换一次方向**（右下 ↔ 左下），按下立即生效，不等松手。左右移动速度固定为下滑速度的 0.7 倍，所以路线是斜线，要预判。
4. 有 **3 条命**（右上角三个红点）。撞到树或石头掉一条命，随后 **0.6 秒减速**、**1.4 秒内无敌**（滑雪者闪烁）。**雪怪**随命数减少逼近：剩 2 条命时从屏幕上沿探头，只剩 1 条时紧贴在身后；最后一次撞击雪怪抓住你，游戏结束。连续 **20 秒**不撞会恢复一条命（最多 3 条）。
5. 下滑速度从 **46 像素/秒**起每秒加 0.5，到 **100 像素/秒**封顶（约 108 秒）。距离按 6 像素 = 1 米计，显示在左上角，结束时显示本次和本次开机内的最远距离；超过先前纪录显示“新纪录”，首局不显示。
6. 结束后 **600ms** 内按键无效，之后按键重来。

任何页面 800ms 内快速三击回菜单。滑雪**不需要**连按：两次转向之间至少隔 0.7 秒（见下节），所以正常玩不会误触三击。

## 雪道保证能滑过去

树木不是随便撒的。每局随机生成一条隐藏的“安全线”，它只会以大约 **0.7 倍斜率**折线移动：每段至少 5 行（70 像素下滑，满速时至少 0.7 秒）后可能转向，碰到活动带（屏幕内 30–130 像素）的边界必转；活动带宽度按“容得下两段最短路线”设定（100 像素 ≥ 98 像素），所以相邻两次转向的间隔不会被边界缩短；改动带宽、斜率或行距时由机器人测试里的“最短转向间隔 ≥ 600ms、不出现三连按”拦住。每一行（每 14 像素）的树木随机放在安全线两侧，**树心到安全线至少 22 像素**，同一行的树互相至少隔 14 像素；起点前 90 像素不放树。这样，跟着安全线按键始终是一条无碰撞的路线，同时屏幕上平均有约 19 个障碍物，看起来不是空的。

## 实现

- `apps/ski/firmware/ski_game.{h,c}`：纯 C 规则，**固定 1ms 步长**，结果只由随机种子和带时间戳的按键决定，与 tick 频率无关。障碍数组固定 40 个，游戏核心 656 字节；加上对象指针，应用会话状态约 1.1 KB，小于 2048 字节会话区（编译期 `_Static_assert` 保证）。
- `apps/ski/firmware/app.c`：全部是 LVGL 控件，雪地背景 + 树（树冠和树干）/石头对象池（只在第一次渲染时创建，之后只移动或隐藏）+ 滑雪者 + 雪怪 + 命数点 + 标题/结算面板。无屏测试里 LVGL 64 KB 堆峰值约 31 KB，与现有“表情”应用相当。

只用 `DOWN` 事件转向，其他事件忽略。

## USB 调试命令

```text
robot ski start
robot ski status
robot ski stop
```

`status`：`phase`（0 待开始 / 1 滑行 / 2 结束）、`meters`、`best`、`lives`、`speed`。

## 验证

```bash
./scripts/test-ski.sh
```

纯 C 测试启用 AddressSanitizer/UBSan，覆盖：斜率、两侧撞墙贴边滑行、不同 tick 节奏逐字节相同、停顿、碰撞盒边界（贴边不撞/压上才撞）、减速、无敌期不重复扣命、雪怪位置随命数、三次撞击结束、500ms 内不能重开、重开后纪录保留、新纪录判定、20 秒回复一条命且不超 3 条；以及机器人模拟：

- 跟随安全线的玩家，20 个种子各 **200 秒**全部零碰撞，滑行约 2800 米，满速 100 像素/秒，**从不需要在 0.8 秒内按三下**，两次转向最短相隔 700ms，每帧屏幕上最多 30 个障碍（数组上限 40）；每 50ms 检查一次：所有树都离安全线 ≥ 22 像素；
- 把转向时机整体提前 **100ms** 仍可 17/20 种子 120 秒零碰撞（其余各只撞一次，全部未结束）；提前 **140ms** 全部会被抓住；延后 **200ms** 仍然零碰撞，延后 240ms 才会失败；
- 从不转向：20/20 在 90 秒内被抓住；每秒盲目转向一次：20/20 在 180 秒内被抓住。

真 LVGL 无屏渲染会开始滑行、转向、被抓住并重来，也断言屏幕汉字都在字库里。

**尚未实机验证**：按键手感、屏幕实际帧率（无屏测试不能证明 FPS，屏幕约每 50ms 刷新）和肉眼难度需要刷机确认；上面的“玩家容错”是机器人对安全线的反应时机，真人看不到安全线，要靠树木间的空隙判断，实际会比机器人难一些。可调参数在 `ski_game.h`：`SKI_SPEED_*`、`SKI_CORRIDOR_HALF`（安全通道宽度，越大越简单）、`SKI_SLOPE`、`SKI_LIVES` 与无敌/减速时间。
