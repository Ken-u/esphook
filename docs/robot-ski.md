# 滑雪大冒险

横版下坡滑雪（类似《阿尔托的冒险》）：雪坡从右向左卷过，滑雪者留在屏幕左侧，**按下起跳，空中继续按住就一直向后翻转，翻满一整圈以上还有额外加分**。单键游戏。

## 玩法

1. 待机短按打开启动器，选择“滑雪冒险”，按住 **500ms** 画满确认圆进入。
2. 标题画面按一下键开始滑行。
3. **按下立即起跳**（不等松手）。**在空中继续按住：每秒向后翻转约 540°**；松手后自动回正到最近的整圈（约 330°/秒）。落地时角度和雪坡相差不到 **75°** 就算安全，否则脑袋着地，游戏结束。
4. **翻满整圈加分**：每翻 1 圈 = 50 分 × 连击倍数，落地角度在 25° 以内算“完美”再加一半。**连续**带翻转的落地让连击倍数加一（最高 ×5），普通落地（空中超过 0.15 秒）清空连击。屏幕左上显示“连击 ×n”，落地时弹出“翻转 ×n +分”。
5. 障碍：**石头**要跳过去，**冰缝**要跳过去（约 600 像素之后出现），沿跳跃弧线挂着的**蓝色宝石**每颗 5 分。撞到石头、掉进冰缝或落地失败都会结束本局。
6. 滑行速度从 **70 像素/秒**起每秒加 0.4，到 **110 像素/秒**封顶。得分 = 距离 / 8 + 翻转加分 + 宝石分。天色随距离从白天渐变到日落、夜晚再到黎明。
7. 结束后 **500ms** 内按键无效，之后按键重来；超过先前最高分显示“新纪录!”，首局不显示。

任何页面 800ms 内快速三击回菜单，所以**空中不要连点三下**。

## 只点一下也能玩

雪坡是种子决定的平滑起伏曲线，障碍之间的间隔按**时间**生成（1.3–2.5 秒），相邻两个障碍到达滑雪者的间隔总够一次完整跳跃。机器人测试按“点一下就松手（60ms）”玩，用规划器在每个障碍前扫描所有按键时刻，**每个障碍至少有 280ms 的合格时间窗**（石头 280–640ms，冰缝 340–660ms）；也就是说不会出现像素级精确的跳跃，不翻转只跳的玩家可以一直滑下去。翻转是“想拿高分才需要”的额外玩法。

## 实现

- `apps/ski/firmware/ski_game.{h,c}`：纯 C 规则，无 ESP/LVGL 依赖。**固定 1ms 步长**，结果只由随机种子和带时间戳的按键决定，与 tick/刷新频率无关；停顿超过 2 秒视为暂停。地形是种子和横坐标的纯函数（带解析斜率），障碍/宝石用相对坐标列表。游戏核心 384 字节，应用会话状态远小于 2048 字节会话区（编译期 `_Static_assert` 保证）。
- `apps/ski/firmware/app.c`：用框架共享的 **160×64 画布** `app_ui_pixels()` 逐像素绘制：分四种时间段调色板（白天 / 日落 / 夜晚 / 黎明，之间平滑渐变）、渐变天空、星星和太阳/月亮、两层视差远山、松树、起伏雪面（带高光和阴影）、石头、冰缝、宝石、骑手（绕重心旋转）、雪粉；上下各有 8 像素色带，得分/宝石/连击/弹出文字是半透明 LVGL 小面板。退出时刷新共享画布，把它交给下一个应用。绘图函数在 `framework/include/esphook/app_gfx.h`（有裁剪的软件绘图、抖动渐变、调色板点阵、半透明叠加、山脉/云/太阳）。
- 无屏测试里 LVGL 64KB 堆占用约 11 KB。

按键事件用 `DOWN` / `UP` / `CANCEL`：`DOWN` 起跳，空中保持 `DOWN` 状态就持续翻转，`UP` 与 `CANCEL`（USB 按住租约失效）松手。`SHORT` / `CONFIRM` 忽略，不再重复触发。

## USB 调试命令

```text
robot ski start
robot ski status
robot ski stop
```

`status`：`phase`（0 待开始 / 1 滑行 / 2 结束）、`score`、`best`、`flips`（本局已落地的翻转圈数）、`gems`、`speed`。

## 验证

```bash
./scripts/test-ski.sh
```

纯 C 测试启用 AddressSanitizer/UBSan，覆盖：地形斜率范围；起跳高度/滞空；按住翻转的速度、松手回正到整圈、落地角度容差内外的安全/失败；整圈加分、连击倍数与“完美”加成；石头/冰缝/宝石碰撞边界；不同 tick 节奏逐字节相同；停顿；撞击后冻结、500ms 内不能重开、重开后最高分保留、新纪录判定；以及机器人模拟：

- **只点一下**的规划器玩家：6 个种子各 100 秒零失败，每个障碍都有至少 280ms 的合格时间窗；
- 把按键时机统一提前或推迟 **120ms**：6/6 种子 45 秒零失败；**180ms** 才会开始失败（仅打印，不作断言）；
- **追翻转**的玩家（空中按住、挑一个能安全回正的松手时机）：4 个种子各 90 秒零失败，164 次跳跃共落地翻转 163 圈（断言：翻转圈数 ≥ 跳跃次数的一半）；一直按到落地的“全程旋转”玩家 6 个种子 60 秒内也没有因落地失败而结束（仅打印，不作断言）；
- 完全不跳：撞上第一块石头；时机偏 600ms：失败。

真 LVGL 无屏渲染会起跳、空中翻转、撞上并重来，每次截图前检查屏幕汉字都在字库里并断言 LVGL 堆低于 80%。

**尚未实机验证**：按键手感、实际帧率（无屏测试不能证明 FPS）、肉眼难度和观感需要刷机确认。可调参数在 `ski_game.h`：`SKI_JUMP_V` / `SKI_GRAVITY`（跳跃高度与滞空）、`SKI_SPEED_*`、`SKI_SPIN_DPS` / `SKI_LEVEL_DPS`（翻转速度）、`SKI_LAND_TOL_DEG`（落地容差）、`SKI_GAP_MIN_S` / `SKI_GAP_MAX_S`（障碍间隔）、`SKI_FLIP_POINTS` / `SKI_COMBO_MAX`（加分）。
